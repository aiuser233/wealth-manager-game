# 培训后台（P4）与私有化部署

P4 面向"一家试点行内跑通 **部署 → 分配账号 → 看报表**"的闭环。B 端功能全部离线优先，数据不出本机/不出内网。

## 组成

| 模块 | 入口 | 说明 |
|---|---|---|
| 学员侧记录 | 游戏内「培训后台」页 | 设置学员编号（可匿名）、导出学习记录 JSON、可选配置内网收集端点 |
| 讲师聚合报表 | 「培训后台」页 | 导入多份学员记录 → 通过率/弱项地图/剧情抉择分布/活跃度/合规红线 → 导出 HTML（打印即 PDF） |
| 行内题包热加载 | 「培训后台」页 | 合规部门提交 JSON 题包，导入时自动跑禁语/机构名/结构机器闸，通过即并入抽题池 |
| 讲师模式大屏 | 「讲师模式」页 | 17 个关键行情日逐幕投影：新闻原文+市场冲击+讨论题+班级举手投票分支分布 |
| 收集端点（可选） | `npm run collect` | 零依赖 Node 服务，学员记录落盘 JSONL，仅内网 |

## 数据模型

学员记录（`fm-student-record` schema v1，见 [packages/ui/src/lms.ts](packages/ui/src/lms.ts)）：

```jsonc
{
  "schema": "fm-student-record",
  "version": 1,
  "studentId": "G2001",            // 培训部门分配，空则 anon_姓名
  "gameDate": "2007-06-01",        // 游戏内进度
  "certs": ["银行业专业基础"],       // 考证
  "exams": [ { "examName": "...", "passed": true, "scorePct": 82, "at": "..." } ],
  "weakTags": { "suitability": 5 }, // 错题知识点聚合
  "choices": [ { "questTitle": "...", "grade": "best" } ],  // 剧情抉择态度数据
  "activeDays": ["2007-01-02"],    // 学习活跃日
  "violations": 0, "questsDone": 5
}
```

隐私设计：匿名编号、无客户真实信息、导出/上传都需要学员主动操作。`grade`（best/good/normal/bad）是天然的态度分布数据，聚合后即为规划书要求的"剧情抉择分布"。

## 行内题包格式

```jsonc
[
  {
    "id": "branch_001",              // 必填，全局唯一
    "subject": "exam_bank_law",      // 必填：exam_bank_law / exam_bank_pf / exam_fund / exam_securities / exam_afp / exam_cfp
    "type": "single",                // single / multiple / judge
    "stem": "题干",
    "options": ["选项A", "选项B", "选项C", "选项D"],
    "answer": 0,                     // 下标；多选为数组 [0,2]
    "explanation": "解析",
    "knowledge_tags": ["suitability"],
    "difficulty": 2,
    "source_note": "行内制度第X条",
    "era_year": 2007                 // 可选：题面涉及的年代（年代穿越检查用）
  }
]
```

导入机器闸与 content-tools 同源：**禁语（保本保息/稳赚…）→ 真实机构名 → 年代穿越 → 答案下标/结构**，任何一项失败整包拒绝并逐条指出问题。教学引用用 `「」` 包裹可豁免（如"以下哪项属于「稳赚不赔」"）。

## 私有化部署方案

### 形态 A：纯单机（默认，零部署）
- 桌面：Tauri 安装包（P3 产物）双机分发，存档在 `%APPDATA%/重生之我是理财经理/fm_save.json`
- Web：内网静态服务器托管 `packages/ui/dist`，学员浏览器打开即玩（localStorage 存档）
- 报表：学员导出 JSON → 讲师导入聚合，U 盘/内网邮件均可传递

### 形态 B：内网收集端点（推荐试点）
```bash
# 培训部任意一台内网机器
npm run collect -- --host 0.0.0.0 --port 8787
# 学员端「培训后台」配置收集端点 http://<该机器内网IP>:8787/collect
# 统计页 http://<该机器内网IP>:8787/stats
```
- 无数据库：记录按日追加 JSONL 文件，IT 部门可直接纳入备份
- 学员也可继续本地导出，两条通道并存

### 形态 C：行内应用市场分发
- Tauri NSIS 安装包已签名后可入行内软件分发系统
- 自动更新留占位（tauri-plugin-updater + 内网更新源），P5 按需启用

## 合规部门对接清单

1. 拿 P1 的双审数据结构（`review.status/source_notes`）审存量 485 题
2. 行内产品/话术类题目按"行内题包格式"提交 JSON，不走代码构建
3. 学习记录仅聚合统计、匿名编号，无个人信息字段——可对照记录 schema 评审
