## 1. 项目概述

### 1.1 一句话定位
一款「重生 + 银行职场」题材的**中大型**视觉小说 × 模拟经营单机游戏：玩家扮演重生回 2006 年的华尔街明星基金经理，在 A 国商业银行从见习理财经理做起，**历经 20 年完整经济周期**（疯牛、次贷、四万亿、钱荒、杠杆牛熊、贸易战、疫情、破净潮、AI 浪潮），最终成长为私行掌舵人或选择自己的终局，全程与真实金融史蓝本同行，**边玩边学一套专业、准确的财富管理知识**。

### 1.2 设计三支柱（核心体验目标）
1. **专业且准确**：所有金融知识、产品机制、监管规则以真实规则为蓝本，由知识体系与双审制把关（第 8 章）；
2. **真实而史诗**：以 2006–2025 真实金融史为蓝本改编，玩家将亲历每一轮泡沫与崩溃的完整周期——上一卷教你在疯牛中守住贪婪，下一卷就要你在崩盘中守住客户；
3. **选择与后果**：短期业绩 vs 长期客户利益、原则 vs 仕途、人 vs AI 的矛盾贯穿 20 年；玩家的每一个决定都在书写自己的职业口碑与结局。

### 1.3 基本信息

| 项目 | 内容 |
|---|---|
| 游戏类型 | 视觉小说（AVG）× 模拟经营（SIM）× 教育向，带轻量 rougelite 式随机事件 |
| 平台 | **Windows 首发**；macOS 同代码同步/紧随发布；iOS / Android 预留移植路径（见第 9 章） |
| 形态 | 单机、买断制、无内购、可离线 |
| 体积 | ≤ 1GB（目标 450–600MB，见 11.2 预算表） |
| 单局时长 | 主线 60–90 小时（20 游戏年）；全结局 + 高重玩性内容 150+ 小时 |
| 目标人群 | 金融从业者、财经专业学生、职场模拟与历史模拟爱好者、财经内容观众（18–40 岁为主） |
| 技术栈 | TypeScript Monorepo + Tauri 2（详细理由与跨平台策略见第 9 章） |

### 1.4 规模定位说明（为什么这是中大型游戏）
- 内容体量：20 游戏年 ≈ 4900 个交易日，60–80 万字文本，350+ 事件，120+ 产品，12 条核心客户 20 年人生线，3600–5000 道题库；
- 系统体量：三档时间帧、因子级市场引擎、行业指数、宏观数据日历、合规、KPI、团队管理、传承等 15+ 子系统；
- 因此流程上采用**章卷制交付 + 每卷数值独立平衡 + Monorepo 并行开发**，而非小游戏的单次打磨。

### 1.5 竞品与差异化
- 参考：《中国式家长》《大多数》（职场成长）、《太吾绘卷》/《了不起的修仙模拟器》（系统深度与随机事件）、《这是我的战争》（时间推进与事件驱动）、股票大作手回忆录式叙事。
- 差异化：① 国内几乎空白的"银行理财经理 20 年"职业史诗题材；② **知识即玩法**（考证、复盘、图鉴三大教学系统 + 真实题库）；③ 以真实金融史为蓝本的完整经济周期模拟，玩家能"活一遍"教科书上的每一轮牛熊。

## 2. 世界观与剧情框架

### 2.1 世界观设定
- **A 国**：架空国度，金融体系以现实为蓝本；机构、指数、产品名全部架空原创，**机制与规则同现实一致**。
- **架空对照原则**：外壳架空（规避商标与"荐股荐基"风险），内核写实；内置**原型图鉴**——事件通关后解锁"现实原型"科普条目（游戏内"玄商 300 指数" ↔ 现实原型"沪深 300 指数"）。
- **时代跨度：2006.1 – 2025.12，整整 20 年**。时代演化不只是行情：柜台的存折与排队长龙 → 2013 手机银行与"宝宝类"冲击 → 2015 股吧与场外配资 → 2020 直播理财与"基金饭圈" → 2023 AI 智能投顾的职业焦虑 → 2025 人机协作。**职场工具、客户行为、监管环境的 20 年演化本身就是玩法与叙事的一部分**（见 6.9 职场演化系统）。

### 2.2 主角与"金手指"规则
- **前世**：林奇安（默认名，玩家可自定义姓名与性别），华尔街"巅峰资本"明星基金经理，管理 80 亿美元，**2026 年初**因长期过劳猝死于办公室。
- **今生**：重生为 A 国"汇诚银行"城东支行校招新人，22 岁，岗位：见习理财经理，入职日 2006-01-09（周一）。
- **金手指三重限制**（防止外挂毁掉游戏性与教学价值）：
  1. **方向性**：记忆碎片只给重大事件的**方向性提示**（"明年市场会疯涨，但记得教客户见好就收"），不给点位、不给标的；
  2. **衰减与蝴蝶效应**：每次调用记忆可信度下降；玩家行为改变世界后，记忆逐渐失准——**你救下的客户、你带火的产品，都会让前世行情偏离**；
  3. **记忆终点**：2018 年后（12 年记忆跨度）记忆彻底归零，此后完全依靠玩家所学。呼应主题：**外挂会过期，专业不会**。

### 2.3 关于"互联网泡沫"等 20 年窗口之外事件的处理（重要设计说明）
20 年窗口（2006–2025）无法容纳 2000 年互联网泡沫。方案：**双通道呈现**——
- **前世记忆通道**：主角 1981 年生，2000 年互联网泡沫破灭时是 19 岁的大学生，前世记忆里存有"亲历往事"碎片，可在特定剧情中以"回忆杀"形式插叙（如 2007 年疯牛时想起"我上辈子听人说过 2000 年纳斯达克的故事，一模一样的疯狂"）；
- **历史复盘室**：知识库设"历史课堂"章节，以模拟 K 线回放 + 讲解卡呈现互联网泡沫、1987 股灾、日本失去的三十年、郁金香狂热等**窗口外的经典周期**，作为可玩化程度较低的"案例课"；
- 若后续想做 **"2001–2005 序章 DLC"**（互联网泡沫 + 非典 + 熊市求生），架构上完全兼容（见 12.2）。

### 2.4 职业主线：五卷 × 20 年 × 职级阶梯

| 卷 | 游戏内年份 | 职级 | 剧情主题 | 市场蓝本主线 |
|---|---|---|---|---|

- **职业阶梯（6 级）**：见习理财经理 → 普通理财经理 → 贵宾理财经理 → 私行理财经理 → 私行团队主管/财富顾问总监 → **终局分支**（分行财富管理部总经理 / 支行行长 / 独立财富顾问·家办 / 隐藏结局"重返投资界" / Bad End）。
- **管理转型**：卷五起从"个人英雄"转向"团队经营"（带 3–5 名下属理财经理），玩法重心从接待转向资源调配与辅导——这是 20 年职业生涯的第二次"新手教学"。

### 2.6 开场 30 分钟（体验流程示例）
1. 重生睁眼：2006-01-09，出租屋，诺基亚手机短信"明日 8:30 晨会，着正装"；
2. 报到：网点晨会（喊口号、读服务规范），认识陈曼与众人；见识**排着长队买基金的大厅**（2006 年的时代切片）；
3. 教学关①：厅堂引导第一位客户办存折取款 → 知识点"存款保险制度（彼时尚未出台，作为历史教学点）+ 利息税"；

## 3. 时间系统（三档时间帧，本作核心创新）

### 3.1 设计原则
- **最小时间粒子 = 交易日**：市场引擎永远按日频演算（4900+ 交易日），保证行情与事件的时间精度；
- **玩法时间帧 = 玩家一次"行动回合"覆盖的现实跨度**，共三档：**日帧 / 周帧 / 月帧**，**最大步长严格为 1 个月**；
- 帧越粗，单回合可分配行动点越多、单回合内的随机事件越密集——用"管理者的一天/一周/一月"映射职级成长。

### 3.2 三档时间帧规格

| 帧 | 单回合跨度 | 行动点(AP) | 核心节奏 | 适用阶段 |
|---|---|---|---|---|
| **日帧** | 1 个工作日 | 4 AP（上午 2 + 下午 2，晚间可选 1） | 精细：逐客接待、逐日行情复盘 | 卷一新人期；所有关键节点 |
| **周帧** | 1 周（5 交易日） | 10 AP | 中观：周计划、批次客户拜访、周度行情 | 卷二起日常 |
| **月帧** | 1 个月（21–23 交易日） | 32–40 AP（月度经营计划一次性分配） | 宏观：经营会议、资源分配、团队管理 | 卷四起日常；月内以随机事件+市场事件打断 |

### 3.3 帧切换规则（四驱动）
1. **职级驱动**：晋升解锁更粗的帧（见习=日帧 → 普通=周帧 → 私行=月帧）；降级/处罚可回退；
2. **事件驱动（镜头拉近）**：重大事件（股灾、破净潮、客户危机、考试日、开门红冲刺、晋升评审、监管检查）**强制切回日帧**，事件结束切回——保证史诗时刻的颗粒度，日常则快速流过；
3. **市场驱动**：市场波动率超阈值 / 持仓客户浮亏超线 / 宏观数据日临近 → 弹出"建议降帧"提示，玩家可一键切日帧逐日应对；
4. **玩家手动**：任意时刻可将"本周/本月"展开为日视图回放（"时间回放"看每一天的行情与流水，但不改变已结算结果）。

### 3.4 月帧内的"过程随机 / 市场驱动"机制（对应需求①）
月帧结算时按序演算：
```
月度经营计划(AP分配) → 逐日推进市场与因子 → 月内随机事件掷骰(客户到访/投诉/同事/家庭)
 → 市场剧变检测(若触发导演事件或波动阈值 → 中断,切日帧处理"突发周")
 → 经济数据日历演出(数据发布/议息/降准) → 月末结算(KPI/绩效/客户损益/到期批量提醒)
 → 月度经营会议(剧情) → 回合结束
```
- **中断机制**：月帧途中检测到"必须玩家亲自处理"的事件（重大客诉、黑天鹅、下属闯祸）时，时间无缝降帧为日帧，处理完再续跑剩余交易日——**玩家永远不会错过关键决策，也不会被无关日常拖慢**。

### 3.5 快进与防拖沓
- 月帧下连续无事发生可一键"跳至下个数据日 / 下个剧情节点 / 下次考试窗口"；
- 全程可调节奏：剧情党可全程日帧细玩，系统党可月帧速推，两条路线的任务达成数值等价（月帧 AP 总量 ≈ 日帧 4×21 的折算）。

## 4. 核心玩法循环

### 4.1 三帧嵌套循环
- **日循环**（教学与事件期）：晨会 → 上午×2AP → 午间事件 → 下午×2AP → 收盘复盘 → 晚间（学习/社交/休息）；
- **周循环**：周一计划会 → 周中 AP 批次执行（外拓、沙龙、售后、学习）→ 周五复盘 + 到期提醒；
- **月循环**：月初经营会议（KPI 拆解、AP 预算分配：客户/团队/学习/合规/生活五桶）→ 月中事件流 → 数据日历演出 → 月末冲时点抉择 → 月度结算。

### 4.2 核心决策循环："接待 → 诊断 → 方案 → 双录成交 → 跟进"
与 v0.9 一致并强化"20 年长线"：
1. **接待**：呈现表面诉求，对话选项挖潜隐藏需求；
2. **诊断**：调阅客户 20 年档案（KYC：年龄/家庭/资产负债/风险测评/现金流/行为标签），找出真实需求；
3. **方案**：从**当时代产品货架**选择组合（2006 年没有净值型理财和智能投顾，2013 年才有宝宝类，2015 年有分级基金，2018 年后净值化……**产品货架本身随时代进化，选错时代的工具本身就是教学点**）；
4. **成交与双录**：适当性校验 → 合规流程 → 业绩计入；
5. **跟进与后果**：跨年、跨卷的长期后果——2007 年你让王奶奶满仓基金，2015 年她会带着孩子来堵你；2021 年你劝住唐薇止盈，2022 年她会把全家资产托付给你。

### 4.3 三条玩家路线与结局
- **业绩型**：晋升快 → 客户流失、投诉与监管风险在更长周期反噬；
- **专业型**：慢但信任复利，解锁私行线、转介绍网络与传承课题；
- **红线型**：飞单/代客操作/承诺收益 → "调查线"（Bad End 教学演出）。
- **六种结局**：调查立案离场 / 平凡退休 / 支行行长 / 分行财富管理部总经理 / 独立财富顾问·开办家办 / 隐藏结局"重返投资界"；另有压力系统触发的"猝死警示"结局（呼应前世死因，20 年过劳线专属）。

### 4.4 压力与生活系统
精力 + 压力双条，20 年跨度上叠加**人生阶段事件**（租房→买房→婚姻可选→生育可选→赡养父母→中年健康危机）：玩家的个人财务决策（2009 年买不买房？2015 年加不加杠杆？）与职业选择互相影响——理财经理首先要管好自己的资产负债表。

## 5. 市场模拟与经济周期系统

### 5.1 因子引擎（全球 + 国内双层）
**全球层**：美联储政策利率、美债 10Y、美元指数、VIX 恐慌指数、原油、黄金、全球风险情绪。
**国内层**：A 股整体（β）、风格因子（大盘/小盘、价值/成长轮动）、行业轮动因子、10Y 国债利率、信用利差、房价、人民币汇率、国内流动性（降准降息）、市场情绪。
- 每因子 = **导演剧本事件 + 均值回复随机 + 跳跃（黑天鹅）**三合成；确定性随机种子（存档可复现，同 seed 同行情）。
- **中美政策背离模块**（"美联储冲突"）：2022 式剧情——美联储激进加息 vs 国内稳增长降息 → 中美利差倒挂 → 汇率贬值压力 → 资金流出压力 → 债市股市承压。教学卡：蒙代尔不可能三角、利差与汇率、出口与汇率。

### 5.2 行业指数与实时表现（对应需求①）
- **31 个行业指数**（仿申万一级风格，全部架空命名），归入 6 大风格族：金融地产 / 周期资源 / 消费 / 医药 / 科技成长 / 稳定公用；

- **行情终端（工作台内嵌"汇诚行情通"）**展示：
  - 指数页：上证综指、玄商 300、中证 500、创业板、恒生、纳斯达克、标普、道琼斯（架空名）；
  - **行业页：31 行业涨跌榜，锚定"距上次查看"的区间涨跌幅**（日/周/月/自上次查看四口径），配色涨跌热力图；
  - 利率与固收页：10Y 国债、LPR、理财平均收益率、货基 7 日年化；

## 6. 系统设计

### 6.1 角色成长系统
- **属性（0–100）**：专业力、沟通力、销售力、**管理力（卷五核心）**、抗压力、行内声誉、客户圈知名度。
- **晋升条件（首版数值，M2 平衡）**：
  - 普通理财经理（2008 末~2009）：银行从业双证 + AUM ≥ 300 万 + 两季考核 B+ + 零合规违规；
  - 贵宾理财经理（2013~2014）：AFP + AUM ≥ 3000 万 + 贵宾客户 ≥ 10 户；
  - 私行理财经理（2018~2019）：CFP + AUM ≥ 1.5 亿 + 私行客户 ≥ 6 户 + 零违规；
  - 私行团队主管（2023~2024）：CPB + 团队 AUM ≥ 5 亿 + 带教 2 人出师 + 行长推荐。
- **技能树** 6 系：投资分析 / 资产配置 / 保险与保障 / 客户经营 / 合规风控 / 团队管理（卷五解锁，含"辅导面谈""绩差员工处理""客户分配公平性"）。

### 6.3 产品系统：跨 20 年的产品进化史
货架随年代解锁/退市，**产品史 = 金融史教学**：
- 2006–2008：凭证式国债、纸黄金、打新基金、首批 QDII（出海折戟事件）、银信合作理财（隐性刚兑教学）；
- 2009–2013：信托"刚兑神话"、结构性存款、**宝宝类货币基金（2013 冲击存款）**、企业债；
- 2014–2018：**分级基金（2015 杠杆屠杀教学重器）**、打新基金 2.0、万能险、智能存款；2018 资管新规后：**净值型理财登场、保本理财谢幕**（网点贴出公告的剧情演出）；
- 2019–2023：固收+、明星主动基金、养老目标 FOF、雪球结构（私行，2022 敲入危机教学）、REITs；

- 产品参数：代码/类型/风险等级/费率/起购/期限/发行方（架空）/市场引擎日频净值/**年代可用区间**。

### 6.4 合规与适当性系统
沿 v0.9 全量保留（销售前校验、禁语检测、红线行为、飞行检查、消保评级、双录），并按监管史演进：
- 2006–2010：宽松年代——"适当性"尚未成文，**搭售与话术诱惑更多**（合规系统教你"没人管你的时候怎么自律"）；
- 2011–2017：销售专区录音录像逐步推行、理财"双录"落地（2017）——新增流程教学关；
- 2018+：资管新规时代——打破刚兑话术重构、禁止保本承诺成为高压线；
- 2019+：互联网贷款与代销新规、适当性办法细化；
- 各年代红线清单不同，**玩家必须随监管更新自己的执业手册**（合规手册 UI 随年代翻页）。

### 6.5 银行经营与 KPI 系统
- KPI 演进：2006 年代考存款时点 + 中间业务 → 2013 年代考理财规模 + 电子银行替代率 → 2020 年代考 AUM + 中收 + 客户数 + MAU → 2025 年代考养老金融 + 财富管理转型指标；**考核指挥棒的变化本身就是行业转型史**；
- 月度 KPI 看板、全行排名、开门红（每年 Q1）、月末冲时点；
- 绩效公式随年代演化（2006 提成低底薪高 → 2025 中收分成制）。

### 6.6 团队与仕途系统（卷五核心）
- **带团队**：3–5 名下属（含周远航），分配客户/辅导培训/绩效面谈/处理闯祸；下属有性格与成长线，可成为你结局的助力或隐患；
- **客户分配博弈**：大客户给谁？公平性影响团队士气与流失率；
- **仕途线**：支行行长推荐、分行关系经营、竞聘述职（现场答辩玩法）——通向管理结局；
- **专业线**：拒绝内卷深耕客户 → 通向独立财富顾问 / 家办结局（离职创业玩法：带走客户的光明面与灰色地带抉择）。

### 6.7 事件系统
- 总量 **350+**：主线剧情事件 90 + 随机事件 200 + 行情复盘卡 60；
- 随机事件按年代标签池化（2006 年代不会有"直播间投诉"，2025 年代不会有"存折挂失"），月帧下高频触发、日帧下低频触发，保证两种节奏体验密度相当。

### 6.8 知识库 / 图鉴 / 复盘室
- **知识库 300+ 词条**（五件套规范不变）+ 交互计算器扩展（IRR、复利、夏普、久期、年金、房贷 vs 投资、汇率换算、养老缺口测算）；
- **历史复盘室**：每次大行情后自动开课（发生了什么/为什么/对你的客户意味着什么/下一次怎么办）+ 窗口外经典周期案例课（互联网泡沫、1987、日本泡沫、郁金香）；
- **原型图鉴**：解锁真实事件对照科普。

### 6.9 职场演化系统（时代氛围包）
网点形态、办公工具、客户沟通渠道、行话黑话随年代变化：存折与柜台 → 网银 → 手机银行 → 直播与私域社群 → AI 工位助手。时代切换时触发"办公环境翻新"演出 + 新教学（如何用企业微信维护客户 vs 2006 年如何发短信群发）。AI 主题贯穿卷五：智能投顾上线事件 → 部分同事转岗 → 主角抉择（拥抱工具/深耕人性化服务/转型管理）。

## 7. 考试与题库系统（对应需求②，独立成章）

### 7.1 总体设计
把"考证"做成游戏内的一条完整成长玩法：**考试日历 → 报名 → 备考（学习行动）→ 模拟真实机考 → 通过/补考 → 证书与业务解锁**。证书是晋升硬门槛，考试本身就是教学过程。

### 7.2 考试科目与日历
- **6 张考卷**（名称对标现实，游戏内用真实证书名以强化职业代入）：
  1. 银行从业·法律法规与综合能力（卷一解锁）
  2. 银行从业·个人理财（卷一解锁）
  3. 基金从业·证券投资基金与销售（卷二解锁）
  4. 证券从业·金融市场基础知识（卷三解锁）
  5. AFP 金融理财师认证（综合卷，卷二解锁）
  6. CFP 国际金融理财师认证（综合卷，卷三解锁）；CPB 作为卷五评审条件（剧情考核而非独立题库）
- **考试窗口：每年 4 次（3 / 6 / 9 / 12 月）**，需提前 1 个月报名（报名费从工资扣），错过顺延下季——与"每 3 月一次"的要求一致；
- 晋升评审、开门红等剧情与考试窗口错峰编排，制造时间管理压力（真实职场写照）。

### 7.3 考场规则（模拟真实机考，题量缩小）
| 规则 | 设定 |
|---|---|
| 每场题量 | **25 题**（在 20–30 间随机），单选 60% / 多选 25% / 判断 15% |
| 限时 | 现实时间 12 分钟（模拟机考倒计时） |
| 及格线 | 60% 正确率；AFP/CFP 卷 70% |
| 出题 | 题库随机抽题，按知识点分布 + 难度配比抽卷；同场不重复题 |
| 分值 | 单选 1 分 / 多选 2 分（漏选得 1）/ 判断 0.5，折算百分制 |
| 结果 | 通过 → 证书 + 属性加成 + 业务解锁 + 剧情演出；不通过 → 可下季补考（时间成本 + 陈曼吐槽） |
| 属性影响 | 专业力与"刷题投入"影响临场发挥（提供 1 次"检查修改"机会对应细心属性） |

### 7.4 题库规格（对应"题库 ≥ 单场 20 倍"）
- **每卷题库 ≥ 600 题（≥ 单场 30 题 × 20 倍）**，六卷合计 **3600 题起步，目标 5000+**；
- 题目 JSON 结构：`{id, subject, chapter, knowledge_tags[], type(单/多/判), stem, options[], answer, explanation, difficulty(1-5), source_note}`；
- **题目来源与版权策略**：以现实考试公开大纲为蓝本，采取"**公开真题回忆版改编 + 依照大纲原创模拟题 + AI 辅助生成 + 金融从业者审校**"三条腿；不整卷照搬任何受版权保护题库，题库内容做原创化改写——既是合规要求，也保证与游戏知识库标签体系对齐；
- 配套功能：**错题本、弱项知识点雷达、每日一题（情绪加成）、考前冲刺卷（消耗 AP 换通过率 buff）、考试后逐题解析回顾**；
- 题库以数据包形式独立存放（`content/exam/*.json`，约 5–8MB），便于后续扩容和按科目分卷下载式更新。

### 7.5 备考玩法
学习行动消耗晚间 AP / 周帧 AP；"刷题"行动直接暴露弱项（雷达图变红）并小幅提升通过率预测；考试前一周有"临时抱佛脚"高风险高回报选项（熬夜刷题：通过率 +10%，次日精力 −30%）。

## 9. 技术架构与跨平台方案（对应需求③，独立成章）

### 9.1 选型结论
**TypeScript Monorepo 分层架构 + Tauri 2 桌面壳**：Windows 首发，macOS 同代码构建，iOS/Android 预留正式移植路径。

| 候选 | 结论 | 理由 |
|---|---|---|
| **Tauri 2 + TS/Vue**（选） | ✅ | 本作 90% 是文本、数据与 UI 逻辑，Web 栈效率最高；Tauri 2 安装包小（~30MB）、内存低；**Tauri 2 官方支持 iOS/Android**，未来可复用 90% 代码移植 |
| Electron | ❌ | 功能可行但安装包 150MB+、内存高，对"精致中大型单机"不划算 |
| Godot 4 | ❌（备选保留） | 引擎能力强，但文本/表格/复杂 UI 密集型游戏其 UI 生态弱于 Web，团队效率低 |
| Unity | ❌ | 体积大、对文本密集型游戏过重 |

### 9.2 分层组织（"以什么方式组织最好"的直接回答）
```
重生之我是理财经理/
├─ packages/
│  ├─ core/        # 纯 TS 引擎：零平台依赖、零 DOM
│  │   time-frame(三档时间帧) · market-sim(因子引擎) · economy(结算)
│  │   client · product · compliance · exam · kpi · quest · save(版本化)
│  ├─ ui/          # Vue 3 表现层：工作台/对话/行情终端/考试/图鉴/设置
│  │   （响应式布局：桌面 16:9 主形态，断点预留移动竖屏形态）
│  ├─ shell-desktop/   # Tauri 2 壳：窗口/文件/存档路径/自动更新（Win + Mac）
│  ├─ shell-mobile/    # Phase 2：Tauri Mobile(首选)/Capacitor(备选)，复用 core+ui
│  └─ content-tools/   # 内容编译器：Markdown/Excel 稿 → JSON + Schema 校验 + Lint
├─ content/        # 全部游戏内容(JSON 数据包)：剧本/事件/产品/客户/题库/知识库
└─ tools/          # 数值模拟器(机器人玩家蒙特卡洛)、平衡性报表、CI 脚本
```
**三条铁律**：
1. **逻辑与表现分离**：`core` 不 import 任何 UI/平台 API，可独立单元测试、可跑无头模拟（数值平衡机器人就靠它）；
2. **内容与引擎分离**：写内容只改 JSON，不改代码；文案用 Markdown/表格写，经 `content-tools` 编译校验入库；
3. **平台能力注入**：文件、对话框、通知等平台差异全部由 shell 层实现接口注入 core/ui，移植 = 换壳。

### 9.3 跨平台移植路线（写进架构，而非事后补）
| 阶段 | 平台 | 方案 | 要点 |
|---|---|---|---|
| 1.0 | Windows | Tauri 2（NSIS/MSI 安装包） | 首发平台，1080p 鼠标键鼠优先 |
| 1.x | macOS | 同一 Tauri 工程 + Apple Silicon 双架构 .dmg 公证 | 构建即可用，成本主要在测试与签名 |
| Phase 2 | iOS / Android | **Tauri Mobile**（同 core+ui）；风险兜底 Capacitor | 竖屏 UI 形态包、触控目标 ≥44px、云存档/本地存档导出 |

**跨平台七条军规**（开发期即遵守，杜绝后期重写）：
① core 零平台 API；② 平台能力走接口注入；③ UI 用 rem/弹性布局 + 断点（桌面 1280–2560 宽全覆盖）；④ 输入统一 pointer events（鼠标/触控同源）；⑤ 存档 schema 版本化 + 迁移器（跨平台存档互通就绪）；⑥ 资源按平台/分辨率分包；⑦ CI 同时产出三平台构建（Windows 日常出包，Mac/Mobile 出冒烟包）。

### 9.4 工程与质量
- 语言/框架：TypeScript + Vue 3 + Pinia；Vitest 单测（core 关键逻辑：市场模拟、适当性校验、时间帧结算、考试抽题）；内容 CI：JSON Schema 校验 + 文案 Lint（禁语词表、术语表一致性）；
- **数值平衡流水线**：`tools/` 内置机器人玩家（三种路线策略）× 1000 局蒙特卡洛无头模拟，输出晋升时点分布、KPI 达成率、结局比例报表——20 年数值没有自动化模拟必死；
- 存档：本地 JSON（3 自动 + 8 手动 + 每日自动），支持导出/导入（未来跨平台云存档就绪）；
- 性能预算：1080p 60fps UI、冷启动 < 3s、内存 < 500MB、存档 < 5MB。
