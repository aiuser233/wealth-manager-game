## 风险与对策
- 追加 tag 可能引入"题不对词"：映射逐条人工复核，一题最多挂 1 个新 tag；改后 lint 复跑。
- 卷七/卷八互斥注册改 state.ts：一周目局若旧档已到 2026+（不可能——旧档日历止于 2025），无兼容问题；但**新档一周目**必须能进卷八，引擎级验证双向各测。
- 2026-2027 随机事件年代字段：RandomEventDef 无强制 era 校验，但 eraDrift 年代水平表止于 2025——近未来事件只走文本层，不挂数值 shock。
- 前缀 aaa~ahh 撞号：生成前 grep 预验证。
- 零引用 tag 分年代桶后 2020-2022 过密：新批 ZERO_TAGS 清单强制 2008-2019 桶占 ≥50%。
- sim 锚点：新导演事件全部 |shock|≤0.05、无 force_day；对照基线 2✗ 口径。
