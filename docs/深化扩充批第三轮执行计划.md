## 风险与对策
- **题-词缝合是本轮灵魂**：生成器断言 + ref-check 机器闸双保险，防止再产"孤儿题"。
- 人生线客户与团队角色同名同人：CLI 档案只补"入队前"节点剧情，入队后剧情归团队系统，避免双重触发（trustReq 梯度控制）。
- 导演事件补盲日期先全量 grep 避让；sim 锚点三 ✗ 口径与基线比对而非归零（基线既有偏差）。
- 前缀 kz~rz 撞号风险低（两字母+3 数字全库 grep 预验证），exams28+ 文件命名与 import 顺序对齐。
- 彩蛋卷链式 requires 延长到 e14：卷六显示与终评钩子（chooseQuest 的 e7/e8 判断）改为 e14 口径。
- 题库主题与前 27 批查重：新批主题避开"计算强化/行为金融概念/2023 监管框架"等已饱和区，主打实操细节与年代补盲。
