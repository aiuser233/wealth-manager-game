## 文档规范（团队约定）

1. **位置**：项目级文档一律放 `docs/`；子包自描述 README（如 src-tauri）只放"这个包是什么+怎么构建"，细节链接回 docs。
2. **命名**：`docs/` 下用中文短名（与项目语言一致）；历史档案进 `docs/archive/` 并保留原版本号。
3. **登记**：新建文档必须在上面两个清单表各登记一行（按需求找文档表可选项）。
4. **互链**：文档间引用用相对路径链接，不要复制内容——一处维护。
5. **时效**：改了系统/流程/数值，当天同步对应文档；每阶段收尾更新规划合并文档的基线表。
